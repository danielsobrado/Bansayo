## Method

A 240 fps phone films, in one shot, the movement (an LED, a hand clap, or a fast arm swing in
front of the webcam) and the monitor showing the desktop Train or Cameras workspace with the live
skeleton or the knee-angle readout. Latency = phone frames from the event to the first frame in
which the desktop shows it, × 4.17 ms (resolution ± 4 ms). Repeat ≥ 20 times. Record the engine's
stage timings for the same run from the `diagnostics` topic or the shutdown log, so the total can
be split into camera → engine (L-01), engine stages, and engine → pixels.
