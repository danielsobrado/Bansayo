# kinexa-contracts

Every type that crosses a process boundary or is persisted, with `serde` (JSON) and `ts-rs`
(TypeScript) derives. The approved specification is `docs/04-contracts.md`.

## Generated output

`contracts/ts/` (TypeScript, re-exported from `index.ts`) and `contracts/examples/` (golden JSON)
are generated by this crate's tests and must not be edited by hand.

```sh
cargo test -p kinexa-contracts                   # fails, naming each stale/missing/unexpected file
KINEXA_BLESS=1 cargo test -p kinexa-contracts    # rewrites both directories; review the diff
```

The golden values are built in `tests/support/`. The `kinexa.body.v1` reference skeleton and its
proportion table live in `tests/support/skeleton.rs`.
